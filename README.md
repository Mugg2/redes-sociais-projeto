Projeto Rede Social
Sobre o projeto

Este projeto é um banco de dados de uma rede social, desenvolvido utilizando SQL e PostgreSQL.

Modelos

O projeto possui:

Modelo Conceitual
Modelo Lógico
Modelo Físico
Tabelas
Usuários

Armazena os dados dos usuários.

ID
Nome de usuário
Nome completo
E-mail
Senha
Idade
Postagens

Armazena as postagens feitas pelos usuários.

ID
ID do usuário
Conteúdo
Data da postagem
Comentários

Armazena os comentários das postagens.

ID
ID do usuário
ID da postagem
Comentário
Data do comentário
Tecnologias
PostgreSQL
SQL
Objetivo

Criar um banco de dados simples para representar uma rede social e aplicar os conceitos de modelo conceitual, lógico e físico.

Autores

Projeto desenvolvido para fins acadêmicos.
